# Aegis

> **Distributed API Rate Limiting Engine**

Aegis is a distributed API rate limiting engine built with **FastAPI, Redis Lua, PostgreSQL, Docker, and Prometheus**.

It provides atomic rate limiting using Redis Lua scripts to safely enforce request limits across multiple backend instances without race conditions.

## Tech Stack

* FastAPI
* Redis
* Redis Lua Scripts
* PostgreSQL
* SQLAlchemy
* Alembic
* Docker
* Prometheus
* Pytest
* GitHub Actions
